Схема архитектуры — обзор компонентов, не формальная C4-модель. ER-обзор показывает основные связи серверных таблиц; полные типы и ограничения находятся в SQL. UML и BPMN не подменяются обычной блок-схемой с чужим названием. Процесс BPMN отображает успешное сохранение и возврат к вводу; технические сбои рассматриваются отдельно в условиях проверки.

Изображения включены в репозиторий, поэтому получателю не нужен редактор диаграмм. Для обновления используется `python tools/build.py`; нужны Graphviz и зависимости из `stand/requirements.txt`. Файлы шрифтов в репозиторий не входят.
