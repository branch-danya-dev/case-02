# Представление для отправки с резюме

[PDF — 6 страниц](Рогулин-Даниил-кейс-02.pdf) · [Текстовая версия](case.md) · [Главная страница](../README.md)

PDF и текст создаются из `pages.json`, схемы — из `tools/build.py`. Изменять нужно источники, не только готовый PDF.

```bash
python -m pip install -r stand/requirements.txt
python tools/build.py
python tools/check.py
```

Нужны Graphviz (`dot`) и установленный шрифт DejaVu Sans. Файлы шрифтов не распространяются. Сборка создаёт OpenAPI, схемы локальных записей, примеры, доску и PDF. Изображения страниц для визуального контроля находятся в непубликуемой папке `review`.

Ни PDF, ни исходный текст не заявляют реальное внедрение, подтверждённую точность или проведённые коммерческие спринты. Для отправки достаточно PDF и ссылки на репозиторий; исходное приложение — отдельный проект.
