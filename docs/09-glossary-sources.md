# 09. Термины и первоисточники

[Главная страница](../README.md)

## Словарь

| Термин | Пояснение |
|---|---|
| API (Application Programming Interface) | Программный интерфейс: согласованные операции и данные взаимодействия компонентов |
| HTTP | Протокол запросов и ответов, используемый серверным API |
| OpenAPI | Машиночитаемое описание HTTP-операций, форматов данных и ошибок |
| JSON / JSON Schema | Текстовый формат данных и описание правил допустимости такого документа |
| SQL | Язык работы с реляционной базой данных |
| PostgreSQL | Система управления реляционной базой данных |
| Docker / контейнер | Средство запуска компонента с его окружением; не отдельная бизнес-функция |
| Docker Compose | Описание и совместный запуск нескольких контейнеров |
| UML | Стандарт моделирования программных систем; здесь диаграмма последовательности сообщений |
| BPMN | Стандарт графического описания процессов; здесь запись тренировки |
| ER-диаграмма | Сущности данных и отношения между ними |
| Идемпотентность | Повтор той же операции не создаёт дополнительный результат |
| Webhook | Входящее уведомление внешней системы; не безусловное доказательство события |
| Транзакция | Связанные изменения сохраняются вместе или не сохраняются вовсе |
| Аутентификация / авторизация | Проверка личности / проверка её права на действие |
| Сеанс, token | Подтверждённый вход на устройстве и значение, которым подтверждается этот вход в запросе |
| 3D | Трёхмерное представление объекта |
| localStorage / IndexedDB | Хранилище значений / база данных внутри браузера |
| Scrum | Организация работы с общей целью, короткими спринтами, проверкой результата и улучшением работы |
| Product Owner / Scrum Master | Владелец ценности и порядка задач / специалист, помогающий применять Scrum |
| Backlog | Упорядоченный список будущих работ; в тексте используется «список задач» |
| Спринт | Ограниченный период работы над общей целью |
| Kanban / WIP | Управление движением работы / начатая незавершённая работа |
| Definition of Done | Общие критерии завершённости результата; не только «код написан» |
| CI (Continuous Integration) | Автоматическая сборка и проверки изменений в репозитории |

Это справочные основания способов моделирования и проверки. Собственные проектные решения помечены отдельно; стандарты не определяют тариф и политику продукта.
