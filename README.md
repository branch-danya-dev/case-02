# Даниил Рогулин — кейс системного аналитика

## Фитнес-приложение: локальный дневник, расчёты, 3D-прогноз и подписка

Гипотетическое проектирование следующей версии приложения на основе [trening](https://github.com/branch-danya-dev/trening/tree/214a1a5eea48f1cf115fdbff898b9d8d39547187). Исходный проект не изменяется.

Регистрация и платёжный учёт отделяются от тренировочных данных. Фотографии остаются на устройстве всегда. Дневник, замеры и расчёты — локально по умолчанию; будущая передача допускается только с отдельным разрешением пользователя.

Репозиторий предназначен для аналитической документации, контрактов взаимодействия и демонстрационных проверок. Он не является платной версией приложения; внедрение, точность физиологических прогнозов и коммерческий опыт Scrum-команды не заявляются.
